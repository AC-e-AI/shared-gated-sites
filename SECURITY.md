# Security reporting

Report a suspected vulnerability privately through [GitHub private vulnerability reporting](https://github.com/AC-e-AI/shared-gated-sites/security/advisories/new).

Do not put credentials, private customer information or exploit details in public issues.
Include the affected revision, impact and the smallest safe reproduction. Do not test
against production systems or other people's accounts without authorization.

Security fixes are maintained on `main`; historical exports and presentation snapshots
are records rather than separately supported software releases.
